# Консольная BankSystem на C#

### Возможности
- Пополнение счёта: зачисление средств с проверкой суммы
- Снятие средств: с проверкой, что на счёте достаточно денег
- Несколько счетов: у пользователя может быть любое число счетов в разных валютах (RUB, USD, EUR)
- Переводы между счетами: в том числе между счетами в разных валютах, с автоматической конвертацией
- Конвертация по курсу: курсы заданы в коде на текущий день, пересчёт идёт через рубль, результат округляется до копеек
- История операций: каждое пополнение и снятие записывается с датой, типом и суммой
- Пользователи банка: добавление и поиск по имени, повторное имя запрещено
- События: при снятии средств счёт уведомляет подписчиков (`event`)
- Безопасные операции: все проверки выполняются до изменения баланса, поэтому при ошибке деньги не теряются

### Как устроен:
- Bank - учет пользователей и переводы
- Account - Пополнение/вывод средств
- Currency - Виды валют
- CurrencyConverter - Курс валют с конвертацией
- User - Создание пользователя
- Transaction - Вывод логов о действии со средствами
- Program - Основной файл

### Запуск
```bash
git clone <ссылка на репозиторий>
cd BankSystem
dotnet run
```
